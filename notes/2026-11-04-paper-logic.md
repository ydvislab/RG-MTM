# 全文逻辑重构（2026-11-04）：从"一个方法"到"一个框架"

目标：按 PacificVis 优秀论文、TVCG 的标准重新组织全文。这份文档只讲逻辑和证据，不涉及具体措辞。
依据：合作者仓库 `code/results/` 中已有的实验，以及本次新算的 OLR Hovmöller 对照。
每条论断都标明了证据来源；标"新"的是还要补的实验。

---

## 一、一句话主张

> 把二维或三维时变标量场的每一帧压成一条一维轴、再按时间排开，就必须在四种保真度之间取舍：**特征层次（拓扑）、空间位置、时间行为、次要几何**。
> 我们为基于合并树的时间概览写出这个取舍空间的统一表述，**证明每一步取舍至少要付多少代价**，并给出一个只用单一控制量 ε 就能在空间中移动的构造（AnchorMTM）。

这样写，贡献的单位是"一个取舍空间 + 它的价格 + 一个导航方法"，而不是"一个更好的合并树图"。TMTM、ST-MTM、Hovmöller 都成了这个空间里的已知位置。

## 二、四种保真度与经典方法的位置

| 保真度 | 含义 | 指标（已有） |
|---|---|---|
| 拓扑 | 极值都在、数值不变、嵌套和合并值正确 | NMLE（渲染后的合并值误差）、极值是否保留（新，见第四节） |
| 位置 | 特征落在参考轴上的位置 | NROE（只看顺序）、E_pool / E_∞（区间位移） |
| 时间 | 数据在动，图上也该动；图上的动不该来自布局本身 | ME（运动方向读错的比例）、TD（图上的总移动量）、布局跳动 \|Δu−Δq\| |
| 次要几何 | 两两相对距离 | SNS、TW（ST-MTM 的指标） |

经典方法在这个空间里的位置：

| 方法 | 优先保什么 | 与我们公式的关系 |
|---|---|---|
| TMTM | 拓扑 + 时间稳定 | **特例**：η=0，无位置上限，贪心翻转，目标 E_O。官方 C++ 核心逐项一致（`baseline_audit_20261019`：ERA5 和 Wildfire 共 1118 组区间与锚点，0 差异） |
| ST-MTM | 拓扑 + 相对几何 | **特例**：η=0，排序用经典的**最优叶序 OLO**（SciPy），目标 E_G、E_M、E_W（KKT 残差 < 1e-6） |
| 参考投影 | 位置 | **特例**：η=∞ 的端点 |
| AnchorMTM | 位置 + 拓扑，可调 | **特例**：由 ε 控制的一条路径 |
| Hovmöller 图 | 位置精确 + 时间平滑 | **不是特例**：它对丢掉的维度取平均，改变了数值。但可以用同样的指标衡量，是"位置优先"一端的参照 |
| 空间填充曲线（Hilbert、Morton） | 空间邻近 | **不是特例**：逐像素遍历，没有特征层次。可以用同样的指标衡量（合作者有旧协议结果，需按当前协议重跑） |
| MotionRugs、MoReVis、一维投影 | 运动实体或区域 | 输入是轨迹或区域，不是标量场，只在相关工作中定位 |

**修正**：之前建议把 OLO 单独作为对比方法，这是多余的。经典的树状图排序已经通过 ST-MTM 进入了比较。

## 三、"竖条纹"：从弱点变成论点

### 现象

在 OLR 对照图中，AnchorMTM 地图有明显的竖条纹（帧与帧之间不连续），Hovmöller 图在时间上很平滑。

### 关键认识：图上的时间变化有三个来源

1. **数据本身在运动**：应该显示出来。
2. **拓扑事件**：特征的出生、消失、合并。对任何保持拓扑的图来说，这是**被迫**的，而且是信息。
3. **布局跳动**：叶序翻转、宽度和填充变化。这是**可以避免**的，应该度量并压低。

这和全文"被迫误差 vs 可避免误差"的主线是同一个思路，可以作为时间维度上的推广。

### 已有数据的支持

数据来源：`metrics_n1c20261027`、`frontier20261027`、`stmtm_completion20261026`。投影的 TD 近似等于数据本身的运动量，因为投影的布局跳动只有每步 0.3–0.85%。

| 数据 | TD：TMTM / ST-MTM / 精确模式 / 预算 10% / 投影 | ME (%)：TMTM / ST-MTM / 精确模式 / 投影 | 精确模式：布局跳动 / 锚点移动（每步 %） |
|---|---|---|---|
| Storms | 10.1 / 7.2 / 27.8 / 23.8 / **23.1** | 47.1 / 41.3 / 24.0 / 14.4 | 5.05 / 10.30 |
| Wildfires | 11.2 / 8.0 / 8.1 / 3.2 / **2.8** | 39.3 / 35.7 / 34.8 / 33.0 | 4.09 / 5.05 |
| OLR | 8.7 / 2.3 / 8.9 / 8.8 / **8.5** | 44.6 / 21.4 / 5.4 / 5.4 | 1.01 / 5.94 |
| PM2.5 | 38.8 / 7.8 / 76.4 / 69.2 / **69.2** | 45.3 / 51.6 / 44.2 / 49.5 | 2.75 / 13.64 |
| Ring | 1.3 / 2.4 / 3.6 / 2.1 / **2.0** | 64.5 / 34.7 / 31.5 / 12.1 | 2.01 / 2.45 |
| Tangaroa | 64.9 / 138.6 / 173.8 / 140.3 / **39.9** | 97.5 / 70.0 / 52.2 / 30.5 | 2.82 / 2.80 |
| Cylinder | 85.0 / 43.2 / 56.6 / 29.2 / **28.7** | 67.0 / 46.0 / 33.1 / 19.3 | 3.89 / 5.12 |

### 可以成立的论点（已有证据）

1. **"稳定"不等于"忠实"。**
   - 在 Storms 和 PM2.5 上，TMTM、ST-MTM 的 TD 远低于数据本身的运动量（Storms 10.1 / 7.2 对 23.1）。
   - 它们看起来稳定，是因为没有把运动画出来，所以运动误差高：Storms 上 ME 为 47% / 41%，投影为 14%。
   - 在其他数据上，它们的 TD 反而高于数据运动（例如 Cylinder 上 TMTM 为 85.0，数据运动为 28.7），说明那部分移动来自布局，而不是数据。
2. **AnchorMTM 的移动大部分跟着数据走，多出来的部分可以度量，并随预算下降。**
   - OLR 上，布局跳动只占锚点移动的约六分之一（1.01 / 5.94）；
   - 预算 10% 时，Wildfires 和 Cylinder 的 TD 降到接近数据运动（3.2 对 2.8，29.2 对 28.7）。
3. **Hovmöller 的平滑来自平均。** 平均的代价已在 OLR 对照中看到：极值被冲淡（最低值 210 对真实的 181），同一参考位置上的两个特征被合并成一个。

### 必须如实说明的边界

- 体数据上布局跳动很大：Tangaroa 的布局跳动和锚点移动几乎相等（2.82 / 2.80），精确模式的 TD（173.8）远大于数据运动（39.9）。这是真实的局限，要写进局限部分和后续工作，例如在目标函数中加入时间正则。
- OLR 上布局跳动很小，所以 OLR 地图上的竖条纹**主要不是锚点跳动**。更可能来自每天的拓扑变化（OLR 每帧有 2–8 个极值，逐日变化剧烈）和背景填充的变化。**这一点要靠新实验验证（实验 N-C），验证之前不能写成结论。**

## 四、Hovmöller 要不要和其他方法比？要，用一张统一的"保真度记分卡"

Hovmöller 是"位置优先"的经典代表，不应只和 AnchorMTM 两两对比。应该把所有显示方式放进同一张表，用同一套指标打分：

| 显示方式 | 拓扑：极值保留、合并值 | 位置 | 时间：ME、布局跳动 | 次要几何 |
|---|---|---|---|---|
| Hovmöller（沿参考方向） | 新算：极值是否保留为独立凹槽、深度误差 | 按构造精确 | 新算 | 新算 |
| 空间填充曲线 | 旧协议：最大合并误差 46–97%，需重跑 | 新算 | 新算 | 新算 |
| TMTM、ST-MTM | 精确 | 有大量可避免误差 | 稳定，但运动画错 | ST-MTM 最好 |
| 投影 | 树被打破（最大 59%） | 精确 | 最接近数据运动 | 中等 |
| AnchorMTM（ε=0 → ε） | 精确，或不超过 ε | 接近下界 | 跟随数据，另有可度量的跳动 | 较差（如实说明） |

要读出的结论**不是"我们最好"**，而是"每种显示都有一个角落是强项"。只有 AnchorMTM 能用一个控制量在拓扑和位置之间移动，并且每一步的价格都有证书。

**需要新定义的指标**：Hovmöller 和空间填充曲线没有带标签的特征，所以需要一个对所有显示方式都适用的特征保留指标。建议：源数据中的每个极小值，在其参考位置附近 ±δ 范围内，剖面上是否有一个独立的局部极小，以及数值误差是多少。δ 预先固定，不针对数据调整。

## 五、建议的全文结构（9 页）

### 1. 引言（约 1 页）
- 开头：时间概览把每帧的空间压成一条轴。这条轴应该表示什么，取决于读者想读什么（嵌套关系、地理位置、运动、相对距离）。
- 现状：经典显示各占一角。Hovmöller 和投影保位置但丢拓扑；TMTM、ST-MTM 保拓扑，但轴没有空间意义。**没有一种共同的语言来描述从一角走到另一角会丢掉什么、至少要丢多少。**

  1. 取舍空间的统一表述，以及各显示方式的定位；

## 七、不能说的话（论断边界）

- Hovmöller 和空间填充曲线**不是**我们公式的特例，只能说"用同样的指标衡量"。
- 不说"全面优于"。ST-MTM 在 TW 上全部占优、SNS 在多数序列上占优；体数据上的布局跳动是我们的弱项。
- 竖条纹的来源在 N-C 完成之前不下结论。
- 案例中的命名风暴只能写"时间窗对应"，不能写"识别出了某个风暴"（见 `event_correspondence_zh.md`）。
- 地图对比中的 TMTM、ST-MTM 列是"其目标函数在我们的模型中求出的布局"，不是原生输出。原生输出只用于 NROE 等不依赖尺度的指标。
