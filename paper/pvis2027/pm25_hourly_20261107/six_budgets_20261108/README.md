# 逐小时 PM2.5 六档预算逐帧数据（合作者 2026-11-08 提供）

- **来源**：微信 `问题核查_PM25_20261108.zip`（11-08 22:44）。只收入数据、核查说明和她的预览图；她的脚本（package.py、verify.py、code_evidence/）依赖她本机路径，没有收入。
- **内容**：`PM25_six_budgets_per_frame.csv`，ε = 0, 1, 2, 5, 10, 20%，每档 744 帧，共 4464 行。
  - `E_max`：每帧最坏位移，单位为轴长比例。
  - `NMLE_max`：每帧最大合并误差，单位为数值范围比例。
- **核对（11-08，本仓库）**：
  - 各档 E_max 的帧平均为 13.8966 / 10.2956 / 8.3284 / 4.6782 / 2.1482 / 1.1469%；
  - 0% 和 5% 等于表 2 的 Exact 0.1390 和 5% 行 0.0468；
  - 所有帧的合并误差都在预算内。
- **用途**：v21 新图 7（见 `notes/2026-11-08-figure-design.md`）。
- **镜像规则**（她的核查说明第 1 节）：表 2 的基线在第一个锚点和参考都有跨度的帧上计算协方差，为负则整段统一翻转一次。PM2.5 上 TMTM 翻转，ST-MTM 不翻转。四个基准数据用的是同一个函数（`experiments_ratio_p_20261104/source/run.py` 的 `baseline_npe`）。
